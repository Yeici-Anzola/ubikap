# UBIKAP

## 📍 Descripción

**UBIKAP** es una aplicación web pensada para ayudar a las personas a **encontrar, cotizar e ir** a diferentes negocios y servicios de su zona de una manera fácil y rápida.

La plataforma busca conectar a los clientes con las **MIPYMES y negocios locales**, permitiéndoles encontrar productos y servicios de acuerdo con sus necesidades y ubicación.

## 🎯 Objetivo

Facilitar la conexión entre los clientes y los negocios locales mediante una plataforma digital que permita encontrar productos y servicios, consultar información y tomar decisiones de compra de manera más sencilla.

## 🚀 ¿Qué permite hacer UBIKAP?

* 🔎 **Encontrar:** buscar negocios, productos y servicios.
* 💰 **Cotizar:** consultar opciones y comparar alternativas.
* 📍 **Ir:** conocer la ubicación del negocio y dirigirse hasta él.
* 🏪 Descubrir negocios y emprendimientos locales.
* 🗺️ Utilizar herramientas de ubicación para facilitar la búsqueda.

## 💻 Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## 🌐 Proyecto

UBIKAP es un proyecto desarrollado como parte del proceso de formación del **SENA**, enfocado en el desarrollo de soluciones tecnológicas para facilitar la conexión entre usuarios y negocios locales.
